## Automatize tudo com n8n

A v1.5.0 traz integração nativa com o **n8n**, plataforma open-source de automação de workflows. A partir desta versão, eventos do Foxi podem disparar fluxos no n8n via webhooks, e o n8n pode alimentar dados diretamente no Foxi via API.

---

## O que é o n8n?

O [n8n](https://n8n.io) é uma plataforma de automação de workflows com centenas de integrações. Ele é auto-hospedado, com código aberto, e pode ser rodado via Docker com um único comando:

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

## Eventos suportados

O Foxi agora emite os seguintes eventos via webhook para o n8n:

| Evento | Gatilho | Payload |
|---|---|---|
| `lead.created` | Novo lead capturado | `{ email, name, source }` |
| `blog.published` | Post publicado | `{ title, url, author }` |
| `changelog.published` | Nova versão publicada | `{ version, title, date }` |
| `contact.form_submitted` | Formulário enviado | `{ name, email, message }` |
| `newsletter.subscribed` | Novo inscrito | `{ email, source }` |

## Configuração

### 1. Configure o endpoint n8n

Adicione as variáveis de ambiente ao seu `.env`:

```bash
N8N_WEBHOOK_URL=https://seu-n8n.dominio.com/webhook
N8N_API_KEY=sua-chave-api-aqui
N8N_ENABLED=true
```

### 2. Ative a integração no config

```typescript
// src/config/config.ts
export const configData = {
  integrations: {
    n8n: {
      enabled: true,
      webhookUrl: import.meta.env.N8N_WEBHOOK_URL,
    }
  }
}
```

## Exemplo de workflow n8n

Um workflow típico para notificação de novo lead:

1. **Trigger:** Webhook recebe `lead.created`
2. **Filtro:** Verifica se e-mail já existe no HubSpot
3. **Condição:** Se não existe → cria contato no HubSpot
4. **Notificação:** Envia mensagem no Slack `#leads`
5. **CRM:** Adiciona lead à sequência de e-mail no Mailchimp

## Integração com Claude AI

Esta versão também integra o **Claude** como um nó disponível no n8n. Use o nó `Claude - Analyse Lead` para:

- Classificar leads automaticamente por intenção de compra
- Gerar resumos de formulários de contato
- Sugerir respostas personalizadas para o time de vendas
- Detectar spam em formulários antes de processar

> **Requisito:** Você precisa de uma chave de API da Anthropic e do nó Claude instalado no n8n (`npm install n8n-nodes-anthropic`).
