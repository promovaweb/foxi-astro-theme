## Chat ao vivo integrado via Chatwoot

A v1.6.0 integra o **Chatwoot** — plataforma open-source de suporte ao cliente — diretamente ao tema Foxi. Agora seus visitantes podem conversar com sua equipe em tempo real, diretamente no site.

---

## O que é o Chatwoot?

O Chatwoot é uma alternativa open-source ao Intercom e ao Zendesk. Ele centraliza conversas de múltiplos canais em um único painel:

- Chat ao vivo no site
- WhatsApp Business
- E-mail
- Facebook Messenger
- Instagram DMs
- Telegram

---

## Instalação em 3 passos

### Passo 1 — Instale o Chatwoot via Docker

```yaml
# docker-compose.yml
version: '3'
services:
  chatwoot:
    image: chatwoot/chatwoot:latest
    ports:
      - "3000:3000"
    environment:
      - SECRET_KEY_BASE=sua-chave-secreta
      - POSTGRES_HOST=postgres
```

### Passo 2 — Configure o widget no Foxi

```typescript
// src/config/config.ts
export const configData = {
  integrations: {
    chatwoot: {
      enabled: true,
      websiteToken: 'seu-token-aqui',
      baseUrl: 'https://seu-chatwoot.dominio.com',
      position: 'right', // 'left' | 'right'
      locale: 'pt_BR',
    }
  }
}
```

### Passo 3 — Adicione o componente na página

```astro
---
import ChatwootWidget from '@components/ui/ChatwootWidget.astro'
---
<ChatwootWidget />
```

## Integração com n8n

Combine Chatwoot + n8n para criar fluxos automáticos de atendimento:

1. **Nova conversa** → notifica agente disponível no Slack
2. **Conversa sem resposta há 5min** → escalona para supervisor
3. **Conversa encerrada** → envia pesquisa de satisfação por e-mail
4. **Avaliação negativa** → cria ticket urgente no Jira

## Personalização visual

O widget herda a paleta de cores do tema automaticamente. Para personalização manual:

```css
/* src/styles/global.css */
:root {
  --chatwoot-widget-color: theme('colors.primary.500');
  --chatwoot-bubble-color: theme('colors.primary.600');
}
```

---

## Privacidade e LGPD

> **Atenção:** O Chatwoot armazena dados de conversas. Para conformidade com a LGPD, adicione a menção ao widget no seu aviso de privacidade e configure a retenção de dados para no máximo 12 meses no painel do Chatwoot.

## Relatórios e métricas

O painel do Chatwoot fornece as seguintes métricas de atendimento:

- Tempo médio de primeira resposta
- Tempo médio de resolução
- Taxa de satisfação (CSAT)
- Volume de conversas por canal
- Relatório por agente
- Horários de pico de atendimento
