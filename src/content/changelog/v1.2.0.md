## Dark Mode de nova geração

A v1.2.0 refatora completamente a implementação do dark mode do Foxi. Saímos de uma abordagem baseada em classe `.dark` no `<html>` para um sistema de tokens CSS nativos com `prefers-color-scheme` e persistência via `localStorage`.

---

## Por que refatorar?

A abordagem anterior apresentava três problemas críticos:

1. **Flash of Wrong Theme (FOWT)** — a página piscava com o tema errado antes do JavaScript carregar
2. **Inconsistência de tokens** — alguns componentes usavam `dark:` do Tailwind, outros usavam variáveis CSS manuais
3. **Sem respeito à preferência do sistema** — o modo padrão era sempre claro

---

## Nova arquitetura de temas

### Tokens CSS

Todos os temas agora são definidos via variáveis CSS em `src/styles/global.css`:

```css
:root {
  --color-bg: theme('colors.white');
  --color-text: theme('colors.neutral.900');
  --color-surface: theme('colors.neutral.50');
}

.dark {
  --color-bg: theme('colors.neutral.950');
  --color-text: theme('colors.neutral.100');
  --color-surface: theme('colors.neutral.900');
}
```

### Script de hidratação

Um script inline no `<head>` resolve o FOWT:

```html
<script>
  const theme = localStorage.getItem('theme') 
    ?? (window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
  document.documentElement.classList.toggle('dark', theme === 'dark')
</script>
```

## Componentes atualizados

### ThemeToggle.astro

O toggle agora exibe corretamente o ícone correspondente ao tema ativo e tem animação de rotação:

- Ícone de sol para modo claro
- Ícone de lua para modo escuro
- Transição de `rotate-0` para `rotate-180` ao alternar

### Todos os componentes de bloco

Todos os componentes em `src/components/blocks/` foram auditados e agora possuem variantes `dark:` explícitas para todas as propriedades de cor.
