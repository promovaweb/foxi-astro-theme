## O que há de novo nesta versão

Esta versão traz um **redesign completo do sistema de navegação** do Foxi, com foco em usabilidade mobile e acessibilidade aprimorada. A estrutura de menus foi revisada do zero com suporte a megamenu e submenus aninhados.

### Principais mudanças

A nova navegação foi construída sobre três pilares fundamentais:

1. **Acessibilidade total** — conformidade com WCAG 2.1 nível AA
2. **Performance mobile** — transições otimizadas com CSS nativo
3. **Customização via config** — todos os itens de menu são gerenciados em `src/config/navigationBar.ts`

## Melhorias de Acessibilidade

O novo menu implementa os seguintes padrões de acessibilidade:

- Navegação completa via teclado (`Tab`, `Enter`, `Escape`, setas)
- Atributos `aria-expanded`, `aria-haspopup` e `aria-current` em todos os links
- Foco visível em todos os estados interativos
- Suporte a leitores de tela (testado com NVDA e VoiceOver)
- Regiões `landmark` definidas com `<nav>` e `aria-label`

## Configuração do Menu

```typescript
// src/config/navigationBar.ts
export const navigationBarData = {
  links: [
    {
      name: 'Produto',
      href: '/produto',
      megaMenu: [
        { name: 'Funcionalidades', href: '/funcionalidades', icon: 'star' },
        { name: 'Preços', href: '/precos', icon: 'tag' },
      ]
    }
  ]
}
```

## Correções incluídas

> **Nota:** Esta versão inclui todas as correções de segurança da v1.0.6. Recomendamos atualizar imediatamente.

- Corrigido bug de duplicação de eventos `click` no menu mobile
- Removido `z-index` hardcoded que causava sobreposição em modais
- Corrigida animação de abertura do drawer em iOS Safari

## Como migrar da v1.0.x

Caso você tenha customizado a navegação anterior, siga os passos abaixo:

1. Faça backup do seu `src/config/navigationBar.ts`
2. Substitua o componente `Header.astro` pela nova versão
3. Migre os itens de menu para o novo formato de configuração
4. Execute `npm run build` e valide a saída
