## Foxi 2 chegou

A versão **2.0.0** é um marco histórico para o projeto. Esta release representa uma reescrita completa do tema, com foco em **IA nativa**, **automação de ponta a ponta**, **performance máxima** e **developer experience (DX)**.

---

## O que mudou?

### 1. IA Nativa (Built-in AI)

O Foxi não é mais apenas um tema Astro; agora ele é um ambiente pronto para ser manipulado por agentes de IA.

- **Contexto Otimizado**: Estrutura de pastas e nomes de arquivos pensados para consumo por LLMs.
- **Instruções Integradas**: Arquivos `.gemini/` e `.claude/` com regras arquiteturais que guiam a IA na criação de novos componentes.
- **Automação de Conteúdo**: Scripts para gerar metadados SEO e descrições de changelog automaticamente.

### 2. Automação com n8n e Chatwoot

A integração com ferramentas low-code foi elevada para o nível de infraestrutura:

- **Webhooks Prontos**: O Foxi já vem com endpoints configurados para receber dados do n8n.
- **Chat Inteligente**: Integração nativa com Chatwoot, permitindo atendimento humano e bots de IA em uma única interface.

### 3. Performance Extrema

- **Zero JS por padrão**: Otimização agressiva do Astro para carregar apenas o essencial.
- **Imagens Next-Gen**: Uso nativo do componente `<Image>` com suporte a `.webp` e `lazy loading`.
- **CSS Atômico**: Tailwind CSS v4 para um bundle final minúsculo.

---

## Como migrar da v1 para a v2?

> **Aviso:** Devido à reescrita completa, a v2.0.0 contém breaking changes significativas. Não recomendamos a atualização direta sem um plano de migração.

1. Faça backup do seu diretório `src/content/`.
2. Clone o novo repositório da v2.
3. Mova seu conteúdo para a nova estrutura.
4. Revise os novos aliases de path no `tsconfig.json`.
