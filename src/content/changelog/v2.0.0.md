## Foxi 2 chegou

A versão **2.0.0** é um marco histórico para o projeto. Esta release representa uma reescrita completa do tema, com foco em **IA nativa**, **automação de ponta a ponta**, **performance máxima** e **developer experience** de excelência.

> Esta versão tem **breaking changes** significativos. Leia o guia de migração completo antes de atualizar.

---

## O que mudou

### Astro 5 + View Transitions

O Foxi 2 migra para **Astro 5** e adota View Transitions nativamente, proporcionando experiência de aplicação sem recarregamento de página:

- Transições suaves entre páginas com `<ClientRouter />`
- Animações de entrada e saída configuráveis por rota
- Persistent islands — componentes que não reinicializam na navegação
- Prefetch automático de rotas visíveis no viewport

### Nova arquitetura de componentes

| Versão | Abordagem | Componentes |
|---|---|---|
| v1.x | Componentes individuais | ~45 arquivos |
| v2.0 | Design system modular | ~120 arquivos |

## IA Nativa com Claude

O Foxi 2 integra o **Claude** diretamente no processo de criação de conteúdo. O pacote `@foxi/ai` expõe helpers para:

### Geração de conteúdo

```typescript
import { generateBlogPost, generateChangelog } from '@foxi/ai'

// Gera um rascunho de post baseado em tópicos
const draft = await generateBlogPost({
  topic: 'Performance no Astro 5',
  tone: 'técnico',
  length: 'longo',
  model: 'claude-opus-4-5'
})

// Gera changelog baseado no diff do git
const changelog = await generateChangelog({
  from: 'v1.9.0',
  to: 'HEAD',
  model: 'claude-sonnet-4-5'
})
```

### Análise de SEO

```typescript
import { analyzeSEO } from '@foxi/ai'

const report = await analyzeSEO({
  url: 'https://seusite.com/blog/meu-post',
  keywords: ['astro', 'performance', 'web'],
})

console.log(report.score)         // 87/100
console.log(report.suggestions)  // lista de melhorias
```

## Guia de migração resumido

### Breaking changes

1. **Config unificado** — `src/config/*.ts` migrou para `src/config/index.ts`
2. **Aliases atualizados** — `@data/` agora aponta para `src/data/` (antes `src/data/json-files/`)
3. **Schema do blog** — campo `image` agora aceita objeto `{ src, alt }` além de string
4. **Componente Layout** — props `title` e `description` são agora obrigatórias

### Passos de migração

1. Faça backup completo do projeto
2. Atualize as dependências: `npm install foxi@2`
3. Execute o script de migração: `npx foxi-migrate`
4. Valide o build: `npm run build`
5. Teste visualmente todas as páginas
6. Revise os changelogs de breaking changes
