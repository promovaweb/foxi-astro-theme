## Ferramentas de IA na linha de comando

A v1.7.0 documenta e integra duas ferramentas poderosas de IA para desenvolvimento: o **Gemini CLI** do Google e o **GitHub Copilot CLI**. A partir desta versão, o Foxi inclui scripts de configuração e prompts otimizados para uso com ambas as ferramentas.

---

## Gemini CLI

### O que é

O **Gemini CLI** é a ferramenta de linha de comando oficial do Google para interagir com os modelos Gemini diretamente do terminal. Ideal para automação de tarefas de desenvolvimento.

### Instalação

```bash
# Via npm
npm install -g @google/gemini-cli

# Autenticação
gemini auth login

# Verificação
gemini --version
```

### Prompts otimizados para o Foxi

O projeto agora inclui uma pasta `.gemini/` com prompts pré-configurados:

```
.gemini/
├── review-component.md    ← revisa componente Astro
├── write-changelog.md     ← gera entrada de changelog
├── check-a11y.md          ← auditoria de acessibilidade
└── optimize-image.md      ← sugere otimizações de imagem
```

### Exemplo de uso

```bash
# Revisar um componente
gemini run .gemini/review-component.md \
  --file src/components/ui/Button.astro

# Gerar changelog automaticamente
gemini run .gemini/write-changelog.md \
  --from v1.6.0 --to HEAD
```

## GitHub Copilot CLI

### O que é

O **GitHub Copilot CLI** integra o poder do Copilot diretamente no terminal, com três comandos principais:

| Comando | Alias | Uso |
|---|---|---|
| `gh copilot explain` | `??` | Explica um comando shell |
| `gh copilot suggest` | `git?` | Sugere comandos git |
| `gh copilot suggest` | `gh?` | Sugere comandos GitHub CLI |

### Instalação

```bash
# Instalar extensão
gh extension install github/gh-copilot

# Configurar aliases (adicione ao .zshrc ou .bashrc)
eval "$(gh copilot alias -- zsh)"

# Uso
?? "como reverter o último commit sem perder as mudanças"
git? "squash dos últimos 3 commits"
```

| Critério | Gemini CLI | Copilot CLI | Claude Code |
|---|---|---|---|

```markdown
- Todo código deve estar em Português do Brasil
- Use os aliases de path (@components/, @layouts/, etc.)
- Siga as convenções BEM para classes CSS
- Use tokens de cor primary-* e neutral-*
- Consulte o DESIGN.md antes de criar componentes
```

## Fluxo de desenvolvimento com IA

O fluxo recomendado para contribuidores do Foxi usando IA:

1. Use o **Copilot CLI** para navegar no git e resolver conflitos
2. Use o **Gemini CLI** para revisar componentes e gerar documentação
3. Use o **Claude Code** para tarefas complexas de refatoração e arquitetura
4. Sempre revise o output das IAs antes de fazer commit
5. Nunca aceite sugestões de IA sem entender o que foi gerado

> **Lembrete:** Ferramentas de IA são assistentes, não substitutos do julgamento humano. Valide sempre o código gerado antes de integrar ao projeto.
