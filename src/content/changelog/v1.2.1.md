## Ajustes de acessibilidade visual

Versão complementar à v1.2.0, focada em corrigir problemas de contraste identificados em auditoria de acessibilidade realizada com a ferramenta **Colour Contrast Analyser**.

---

## Problemas de contraste corrigidos

Os seguintes pares de cor não atingiam a razão mínima de **4.5:1** exigida pelo WCAG 2.1 AA:

| Elemento | Antes | Depois | Razão antes | Razão depois |
|---|---|---|---|---|
| Texto de legenda | `neutral-400` | `neutral-600` | 3.2:1 | 5.8:1 |
| Placeholder de input | `neutral-300` | `neutral-500` | 2.1:1 | 4.7:1 |
| Badge de status | `primary-300` | `primary-700` | 2.8:1 | 6.1:1 |
| Link em parágrafo | `primary-400` | `primary-600` | 3.6:1 | 5.2:1 |

---

## Novos tokens adicionados

```javascript
// tailwind.config.mjs — novos tokens semânticos
colors: {
  'text-muted': 'var(--color-text-muted)',
  'text-subtle': 'var(--color-text-subtle)',
  'border-default': 'var(--color-border)',
}
```

---

## Regras atualizadas

- Textos de `font-size` menor que `1rem` devem usar razão mínima de **7:1**
- Ícones decorativos devem ter `aria-hidden="true"`
- Ícones informativos devem ter `aria-label` descritivo
- Nunca usar cor como único meio de transmitir informação
