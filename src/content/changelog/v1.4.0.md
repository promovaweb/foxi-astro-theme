## Blog completo para o seu projeto

A v1.4.0 entrega um **sistema de blog totalmente funcional** integrado ao Foxi, construído sobre as Collections do Astro com suporte a paginação, tags, categorias e RSS.

---

## Estrutura do sistema de blog

```text
src/
├── content/
│   └── blog/
│       ├── meu-primeiro-post.md
│       └── segundo-post.md
├── pages/
│   ├── blog/
│   │   ├── [...page].astro       ← listagem paginada
│   │   ├── [id].astro            ← post individual
│   │   └── tag/
│   │       └── [tag]/
│   │           └── [...page].astro ← posts por tag
│   └── rss.xml.ts                ← feed RSS automático
└── content.config.ts             ← schema atualizado
```

---

## Schema do frontmatter

Cada post de blog deve seguir o schema abaixo:

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `title` | `string` | Sim | Título do post |
| `description` | `string` | Sim | Resumo para SEO e listagem |
| `pubDate` | `Date` | Sim | Data de publicação |
| `image` | `string` | Sim | Caminho da imagem de capa |
| `author` | `string` | Sim | Nome do autor |
| `tags` | `string[]` | Sim | Lista de tags (mínimo 1) |

---

## Paginação configurável

O tamanho de página é controlado via `src/config/config.ts`:

```typescript
export const configData = {
  blogPageSize: 6, // posts por página
}
```

---

## Feed RSS automático

O arquivo `src/pages/rss.xml.ts` gera um feed RSS válido automaticamente. Para anunciar o feed, adicione no `<head>`:

```html
<link rel="alternate" type="application/rss+xml" title="Blog Foxi" href="/rss.xml" />
```

## Componentes do blog

### Lista de componentes novos

- `PostCard.astro` — card de post com imagem, título, data e excerpt
- `PostHeader.astro` — cabeçalho do post individual com imagem hero
- `TagBadge.astro` — badge de tag com link para listagem filtrada
- `AuthorCard.astro` — card de autor com avatar e bio
- `RelatedPosts.astro` — seção de posts relacionados por tag
- `ReadingTime.astro` — estimativa de tempo de leitura
- `ShareButtons.astro` — botões de compartilhamento social

---

## Tipografia do blog

O conteúdo dos posts usa a classe `.basic-text` que estiliza automaticamente:

1. Títulos `h1`–`h6` com hierarquia visual clara
2. Parágrafos com `line-height: 1.8` para melhor legibilidade
3. Listas ordenadas e não ordenadas com marcadores estilizados
4. Blocos de código com syntax highlight via Shiki
5. Citações em bloco com borda e fundo destacado
6. Tabelas com bordas e linhas alternadas
7. Links sublinhados com cor `primary-500`
8. Imagens com bordas arredondadas e shadow

---

## Integração com SEO

Cada post gera automaticamente metatags Open Graph e Twitter Card:

> O componente `Layout.astro` integra o plugin `astro-seo`. Passe `title` e `description` adequados em cada página para garantir boa indexação e compartilhamento social.

---

## Como criar um novo post

1. Crie um arquivo `.md` em `src/content/blog/`
2. Preencha o frontmatter conforme o schema
3. Escreva o conteúdo em Markdown
4. Adicione a imagem em `public/blog/`
5. Faça o build e verifique a geração da página

O post aparecerá automaticamente na listagem, no RSS e nas páginas de tag.
