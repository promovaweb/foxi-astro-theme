## Biblioteca de componentes expandida

A v1.3.0 adiciona **11 novos componentes de bloco** ao Foxi, todos documentados no `DESIGN.md` e disponíveis imediatamente para uso em páginas.

---

## Novos componentes de bloco

### Seções de conteúdo

Os seguintes blocos foram adicionados em `src/components/blocks/`:

1. **`Comparison.astro`** — tabela visual de comparação de planos com destaque de coluna
2. **`Timeline.astro`** — linha do tempo vertical com ícones e datas
3. **`Testimonials.astro`** — carrossel de depoimentos com foto, nome e cargo
4. **`LogoCloud.astro`** — grid de logos de parceiros/clientes com escala de cinza e hover colorido
5. **`Stats.astro`** — bloco de métricas com números animados via Intersection Observer
6. **`Accordion.astro`** — FAQ expansível com animação suave
7. **`Team.astro`** — grid de membros da equipe com foto, cargo e links sociais
8. **`Pricing.astro`** — cards de planos com badge de destaque e lista de funcionalidades
9. **`Gallery.astro`** — grade de imagens com lightbox nativo
10. **`Video.astro`** — embed responsivo de vídeo YouTube/Vimeo com poster
11. **`Newsletter.astro`** — formulário de captação de e-mails com validação inline

---

## Componente em destaque: Comparison

O `Comparison.astro` foi o componente mais solicitado pela comunidade. Ele permite criar tabelas de comparação altamente customizáveis:

```astro
---
import Comparison from '@components/blocks/Comparison.astro'

const plans = [
  {
    name: 'Básico',
    price: 'Grátis',
    highlight: false,
    features: ['5 projetos', '1 usuário', 'Suporte por e-mail']
  },
  {
    name: 'Pro',
    price: 'R$ 49/mês',
    highlight: true,
    features: ['Projetos ilimitados', '10 usuários', 'Suporte prioritário']
  }
]
---
<Comparison plans={plans} />
```

## Props dos novos componentes

### Stats.astro

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `items` | `StatItem[]` | — | Lista de métricas |
| `animated` | `boolean` | `true` | Ativa contagem animada |
| `columns` | `2, 3 ou 4` | `4` | Número de colunas |

### Testimonials.astro

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `items` | `Testimonial[]` | — | Lista de depoimentos |
| `autoplay` | `boolean` | `false` | Avança slides automaticamente |
| `interval` | `number` | `5000` | Intervalo em milissegundos |

## Integração com dados JSON

Todos os novos componentes são alimentados por arquivos em `src/data/json-files/`. Nenhum dado deve ser hardcoded nos componentes.

- `src/data/json-files/testimonialsData.json`
- `src/data/json-files/statsData.json`
- `src/data/json-files/teamData.json`
- `src/data/json-files/pricingData.json`
- `src/data/json-files/logosData.json`

---

## Boas práticas de uso

> **Atenção:** Os componentes `Gallery.astro` e `Video.astro` carregam scripts adicionais. Use a diretiva `client:visible` para adiar o carregamento até que o componente esteja na viewport.

- Sempre passe `alt` descritivo para imagens no `Gallery.astro`
- O `Video.astro` aceita IDs do YouTube **ou** URLs completas do Vimeo
- Use `animated: false` no `Stats.astro` para usuários que preferem movimento reduzido
