## Deploy e gerenciamento simplificado com Portainer

A v1.8.0 entrega **stack completa para deploy do Foxi com Portainer**, incluindo templates prontos para orquestrar o Foxi junto com todas as suas integrações (n8n, Chatwoot, banco de dados) em um único ambiente Docker gerenciado.

---

## O que é o Portainer?

O **Portainer** é uma interface web open-source para gerenciamento de containers Docker e Kubernetes. Com ele, você faz deploy, monitora e gerencia toda a stack do Foxi via navegador, sem precisar digitar comandos Docker manualmente.

---

## Stack completa do Foxi

O arquivo `docker/stack.yml` no repositório define toda a infraestrutura necessária:

```yaml
version: '3.8'

services:
  # Foxi — site estático servido via Nginx
  foxi:
    image: nginx:alpine
    volumes:
      - ./dist:/usr/share/nginx/html:ro
      - ./docker/nginx.conf:/etc/nginx/nginx.conf:ro
    ports:
      - "80:80"
      - "443:443"
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.foxi.rule=Host(`seusite.com`)"

  # n8n — automação de workflows
  n8n:
    image: n8nio/n8n:latest
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=${N8N_USER}
      - N8N_BASIC_AUTH_PASSWORD=${N8N_PASSWORD}
    volumes:
      - n8n_data:/home/node/.n8n

  # Chatwoot — chat ao vivo
  chatwoot:
    image: chatwoot/chatwoot:latest
    environment:
      - SECRET_KEY_BASE=${CHATWOOT_SECRET}
      - POSTGRES_HOST=postgres
    depends_on:
      - postgres
      - redis

  # Banco de dados
  postgres:
    image: postgres:15-alpine
    environment:
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data

  # Cache
  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  n8n_data:
  postgres_data:
  redis_data:
```

## Deploy via Portainer

### Método 1 — Stack via URL do repositório

1. Acesse **Stacks → Add Stack** no Portainer
2. Selecione **Repository**
3. Informe a URL do repositório e o caminho `docker/stack.yml`
4. Configure as variáveis de ambiente
5. Clique em **Deploy the stack**

### Método 2 — Stack via editor web

1. Acesse **Stacks → Add Stack**
2. Selecione **Web editor**
3. Cole o conteúdo do `docker/stack.yml`
4. Configure as variáveis e faça o deploy

---

## Variáveis de ambiente obrigatórias

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `N8N_USER` | Usuário do n8n | `admin` |
| `N8N_PASSWORD` | Senha do n8n | `senha-segura` |
| `CHATWOOT_SECRET` | Chave secreta do Chatwoot | `chave-base64` |
| `POSTGRES_PASSWORD` | Senha do PostgreSQL | `db-senha-forte` |
| `DOMAIN` | Domínio do site | `seusite.com` |

## Monitoramento via Portainer

Com a stack rodando, o Portainer oferece:

- **Logs em tempo real** de cada container
- **Métricas de CPU e memória** por serviço
- **Controles de ciclo de vida** (start, stop, restart, scale)
- **Console interativo** para debug
- **Alertas** via webhook quando container cai

## Backups automáticos

A stack inclui um serviço de backup automático baseado em `restic`:

- Backup diário do banco de dados PostgreSQL
- Backup semanal dos volumes Docker
- Retenção de 30 dias
- Notificação via n8n em caso de falha

> **Boas práticas de segurança:** Nunca exponha o Portainer diretamente na internet sem autenticação. Use sempre HTTPS e considere restringir o acesso por IP ou VPN.
